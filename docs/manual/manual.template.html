第 1 章　认识界面

Glyph 的界面按「数据 → 图形 → 产出」的顺序分成三大区域，配合顶部工具栏与底部状态栏，形成一个从左到右的绘图流水线。

1.1 三大区域

区域位置作用
数据区左侧导入数据、选择内置数据集、查看列信息与数据预览、进入数据准备
画布区中间显示渲染结果；顶部可切换「图表 / 代码」两种视图；底部是可折叠的数据统计抽屉
控件区右侧12 个功能页签，从添加图层到导出设置的全套参数
左右侧栏都可以收起。点左侧栏顶部的 ‹、右侧栏顶部的 › 可以折叠，把屏幕留给画布；收起后底栏会出现对应的图标按钮，功能不变。

1.2 顶部工具栏

画布顶栏从左到右依次是：

控件说明
撤销 / 重做快捷键 Ctrl+Z / Ctrl+Y
图表 / 代码切换画布的两种视图。代码视图不参与渲染，只展示当前图形对应的 R 代码
缩放按钮在「适合窗口」与「1:1 原始像素」之间切换
画幅标签显示当前渲染尺寸与 dpi，点击可打开尺寸设置面板
自动渲染开关开启时改动即出图；关闭后需手动点「渲染」，适合调参阶段减少等待
渲染按钮立即重新渲染
自适应画布。画幅标签里有一个「自适应画布」开关，默认开启：渲染分辨率会跟随画布窗口大小自动调整， 所以在大屏或拉宽侧栏后，图会自动变得更清晰，而不是被拉伸放大。手动修改画幅或 dpi 后会关闭自适应，避免设置被窗口尺寸覆盖。

1.3 底部状态栏

底栏左侧显示保存状态与当前数据源，中间显示画布状态，右侧集中了产出类动作：

存入图库 / 更新图库交互预览导出检查可复现包导出

最左侧还有暗色模式切换、退出服务与「项目」下拉菜单（保存 / 载入项目、清空画布）。

1.4 右侧控件页签分组

12 个页签按职责分成 5 组，组间有分隔线：

分组页签用途
绘图核心图层 · 美学 · 参数决定「画什么、映射什么、怎么细调」
图形设置标度 · 坐标改变图形本身的呈现规则
图上元素标签 · 注释 · 主题叠加在图上、影响外观的内容
产出图库 · 拼图把图存档、把多张图组合起来
系统高级 · 扩展代码模式与能力管理

第 2 章　准备数据

Glyph 支持 ggplot2 内置数据集与你自己导入的数据。选好数据后，左侧会列出所有列及其类型与唯一值个数。

2.1 选择内置数据集

  1. 在左侧「内置数据集」下拉框中选择一个数据集，例如「汽车油耗测试数据（234×11）」。
  2. 选择后，下方「列」面板会列出全部列：chr 表示字符型，num 表示数值型，右侧数字是唯一值个数。
  3. 点击列名可以展开预览，「预览」按钮会打开数据表视图。

2.2 导入自己的数据

点左上角「导入数据」可以选择文件（CSV / Excel 等）导入；也可以在导入向导里直接粘贴表格数据。导入后的数据出现在「我的数据」分组下，可以像内置数据集一样使用。

数据是引用而不是副本。图库条目与项目文件保存的是「数据源 + 加工步骤」，而不是数据本身。 因此如果你删除了导入的数据文件，引用它的图需要重新指定数据源。

2.3 数据准备流水线

点「数据准备」打开加工面板。这里的 7 个步骤是按固定顺序执行的，每一步都可以单独启用或停用：

顺序步骤说明
1类型转换先转换类型，再做筛选或派生。例如把数值列转成因子用于分组
2文本清洗去空格、统一大小写、字符串替换
3异常值按 IQR 或 z-score 标记异常值。默认只标记，不删除数据
4新增列先于筛选执行，供后续筛选与绘图使用
5缺失值按所选列删除含缺失的行，可选「任一缺失」或「全部缺失」
6缺失值填充用常数、均值、中位数或众数填充
7行筛选写 R 逻辑表达式；点击下方列名可直接插入
原始数据不会被修改。所有步骤都只在渲染时应用，面板顶部会显示「原始 234×11 → 当前 234×11」这样的对比，随时可以重置。

第 3 章　画出第一张图

一张图由一个或多个「图层」叠加而成。每个图层包含三部分：用哪种几何对象（geom）、把数据列映射到哪些视觉属性（aes）、以及各种参数。

3.1 添加图层

  1. 画布为空时，中间的引导页有一个「添加第一个图层」按钮，点击即添加一个默认的散点图图层。
  2. Glyph 会尝试自动猜测两列做映射。如果猜得不合适，到「美学」页签改成你需要的列。
  3. 修改后图会自动重新渲染（自动渲染开着的情况下），右下角状态栏会显示渲染耗时。

3.2 图层管理

「图层」页签列出当前所有图层，从下到上对应绘制的先后顺序（后画的盖在上面）。每个图层右侧有几个图标按钮：

操作说明
点击图层条目选中该图层，后面的「美学」「参数」页签都会针对它生效
眼睛图标临时隐藏 / 显示该图层，用于对比效果
上下箭头调整绘制顺序
复制图标复制一份图层，适合在相似配置上做微调
垃圾桶删除图层
右上角「+ 添加图层」新增图层；顶部会显示「共 N 层」
多图层是 ggplot2 的核心能力。例如散点图叠加拟合线：先加一个 point 图层， 再加一个 smooth 图层并勾选只显示线不显示置信带，两者共享同一套坐标与主题。

3.3 美学映射

「美学」页签决定数据列如何映射到视觉属性。每一行的结构是：属性名 + 映射/常量开关 + 取值。

模式含义
映射把某个数据列映射到该属性。例如把 class 映射到 colour，不同类别会显示不同颜色，并自动生成图例
常量给该属性一个固定值，不参与映射。例如把 size 设为常量 3，所有点一样大

可用的属性包括 x、y、shape（形状）、colour（颜色）、fill（填充）、size（大小）、alpha（透明度）、stroke（描边宽）、group（分组）。带 * 号的是该 geom 必需的属性。

页签下方的「图层开关」还可以设置 inherit.aes 与 show.legend。

映射与常量的区别很重要。想要「所有点统一红色」，用常量；想要「不同类别不同颜色」，用映射。 把常量误设成映射会凭空多出一个图例。

3.4 参数调整

「美学」管的是映射关系，「参数」管的是函数内部的具体行为。这里分四块：

  • geom / stat 参数：当前几何对象特有的参数，例如柱状图的 width、密度图的 bw、na.rm 等。
  • stat 选择：更换统计变换，例如把 identity 换成 bin 或 smooth。
  • position 调整：处理重叠位置，例如 dodge（并排）、stack（堆叠）、jitter（抖动）。
  • 常量美学：不进入 aes 的固定外观值。

第 4 章　图形设置

4.1 标度

标度控制「数据值 → 视觉值」的转换规则。打开「标度」页签后，先选择要调整的标度类型（对应某个 aes），再设置它的参数。

典型用途：

  • 颜色：换成期刊友好的配色、设置渐变端点色
  • 坐标轴范围：限定 x/y 的显示区间
  • 坐标变换：对数刻度、反向刻度
  • 标签：自定义刻度文字、图例标题
不确定要不要加标度？可以先不加。ggplot2 会按数据类型自动给出合理的默认标度，只有需要改配色、范围或变换时才手动添加。

4.2 坐标系与分面

坐标系常用的是 coord_flip()（横纵互换，适合长类别名的条形图）和 coord_fixed()（固定纵横比，适合需要保持比例的场景）。

分面把一个图拆成多个小图。facet_wrap 按一个或多个变量自动排布；facet_grid 用行 × 列两个维度交叉排布。可以设置分面标签位置与是否固定坐标轴刻度。

第 5 章　美化与标注

5.1 标签

「标签」页签设置标题、副标题、坐标轴标签、图例标题等文字内容。

页签分三块：

  • 图表标签（labs）：主标题、副标题、说明文字、x/y 轴标题
  • 图例标题：每个 aes 映射的图例标题，可以单独命名
  • 图例 / 引导（guides）：控制图例位置、是否显示、连续色条的方向等

5.2 注释

「注释」页签用于在图上叠加说明性元素，例如参考线、文字标注、显著性标记等。这类元素不参与数据映射，只做视觉强调。

5.3 主题

主题决定图表的整体外观：背景、网格线、字体、轴线等。Glyph 默认使用期刊风格的 Prism 主题。

页签分两层：

  • 基础主题：选一个预设（如 theme_minimal、theme_bw、theme_prism），一次性改变整体风格
  • 元素设置：在预设之上逐项微调，例如网格线粗细、轴文字字号、图例位置
建议顺序：先选基础主题，再改元素。反过来先改元素再换主题，元素设置可能需要重做。

第 6 章　数据统计

画布底部的「数据统计」抽屉把常用的统计分析放在绘图界面里，算完可以直接落到图上，省去在 R 与图表之间来回切换。

6.1 描述统计

  1. 点底栏「▸ 数据统计」展开抽屉。
  2. 在「统计变量」里选择一个或多个数值列。
  3. 可选地设置「分组变量」，会按组分别统计并追加一行合计。
  4. 点击「计算」。

结果表包含：变量、分组、n、缺失、均值、SD、中位数、Q1、Q3、最小、最大。右上角的「代码」按钮可以查看对应的 R 代码。

6.2 统计检验与回归

切到「统计检验」可以完成组间比较，切到「回归分析」可以做线性拟合与结果解读。两者都会给出统计量与 p 值，并可直接生成图上标注。

6.3 图表建议与图上标注

页签作用
图表建议根据当前数据的变量类型推荐合适的图形类型
图上标注把显著性括号、p 值、样本量等标注直接画到图上

6.4 基线表

「基线表」用于生成论文中常见的「Table 1」——按分组列出各变量的统计描述。这是临床研究论文的标配表格。

第 7 章　导出图形

7.1 画幅与自适应

点顶栏的画幅标签（形如 1188×668 · 150dpi）打开尺寸设置面板：

设置说明
像素 / 毫米两种输入方式。投期刊建议用毫米，直接填目标印刷尺寸
预设单栏 85 mm、1.5 栏 114 mm、双栏 170 mm、Nature 89 mm
自适应画布开启时渲染尺寸跟随窗口；手动改画幅后自动关闭
预览 / 导出这是两套独立设置：预览追求速度，导出追求精度（默认 300 dpi）
预览尺寸不影响导出质量。预览用低分辨率是为了让调参更快，导出时会按「导出」那一栏的设置重新渲染。

7.2 导出前检查

点底栏「导出检查」，或导出时自动触发，会对当前图形做规范性检查：

检查项说明
白底期刊通常要求背景为白色，深色主题会被提示
位图分辨率检查 dpi 是否达到目标期刊要求（一般 ≥300）
物理尺寸检查宽度是否符合期刊栏宽
字体检查是否使用了期刊允许的字体
文字字号检查最小字号是否达到下限（以免印刷后不可读）

7.3 格式与期刊模板

导出支持 PNG（位图）、SVG（矢量）、PDF（矢量）。矢量格式放大不失真，是投稿首选。

右上角可以选择「目标期刊」，检查规则会随之切换：

模板栏宽最小字号推荐格式
通用—6 ptpng / svg / pdf
Nature89 mm5 ptpdf / svg / png
Science55 mm5 ptpdf / svg
Cell85 mm6 ptpdf / svg / png
PLOS83 mm6 pttiff / eps / pdf
IEEE88 mm8 ptpdf / svg
中文核心85 mm7 ptpdf / svg / png

7.4 可复现包

点底栏「可复现包」会导出一个压缩包，里面包含生成这张图的完整 R 脚本与所用数据。把它交给合作者或几个月后的自己，可以直接复现出同一张图，不依赖 Glyph。

投稿前建议。除了导出图片本身，也顺手导出一份可复现包存档——期刊常会要求提供绘图代码，审稿阶段也常需要改细节重出图。

第 8 章　图库

图库用来存档已经调好的图，之后可以随时取回复用、参与拼图组合，或者打开继续编辑。

8.1 存入与更新

  1. 调好一张图后，点图库页顶部「存入当前绘图」（或底栏的「存入图库」）。
  2. 保存成功后会生成一个新条目，卡片显示缩略图、层数与数据源。
  3. 继续修改这张图后再存，按钮会变成 「更新到「条目名」」，点击即覆盖更新原条目，名称保持不变。
  4. 如果想保留旧版本、另存一份，点按钮右侧的下拉箭头，选「另存为新条目」。
更新 vs 另存。从图库打开某张图、改完再存，默认是「更新原条目」——这样不会每次微调都产生一条新记录。 需要保留历史版本时才用「另存为新条目」。

8.2 重命名与删除

  • 重命名：点卡片名称右侧的铅笔图标，名称会变成输入框。回车或点别处保存，Esc 取消。
  • 删除：点卡片右下角的垃圾桶图标，需要确认。

8.3 打开并继续编辑

点击任意卡片即可把这张图重新载入画布：

卡片类型打开后的效果
普通图还原完整的绘图规格以及它使用的数据集，可以直接继续编辑图层、标度、主题
代码图（带「代码」徽标）还原为一段代码绘制出的图。需要修改时，到「代码」视图点「载入编辑器」送到高级页编辑运行
打开会切换数据集。因为图层映射只对生成它的那个数据集有意义，所以打开图库条目时会连数据源一起切换。 如果当前画布有未保存的改动，会先弹窗确认。

打开代码图后，画布顶栏会显示橙色的「代码图」标签和一个「返回我的图」按钮，点它可以切回你原本用图层搭出来的图。

第 9 章　拼图组合

把图库里的多张图组合成一张出版级的多面板图，底层由 patchwork 驱动。

  1. 先把要组合的图都存入图库。
  2. 到「拼图」页签，点「从图库选择…」打开选择弹窗，勾选多张图。
  3. 在「组合序列」里调整顺序与运算符：+ 表示并排，/ 表示上下堆叠。
  4. 在「plot_layout」里设置行列数、各面板的相对宽度 / 高度比例。
  5. 在「plot_annotation」里设置整张图的标题、副标题、说明文字与子图编号（A/B/C）。
  6. 展开「标注样式」可以单独调整标注的字号、加粗、颜色与字体。
标注样式只影响标注层。plot_annotation 的主题只作用于整体的标题、副标题、说明与编号， 不会改变各个子图内部的字号。子图的字号要到各自的「主题 → 元素设置」里改，或者调整基础主题的 base_size。

第 10 章　代码视图与编辑器

10.1 代码视图

点画布顶栏的「代码」切换到代码视图。这里显示的是用当前绘图规格自动生成的 R 代码，可以直接复制粘贴到 RStudio / Positron 运行。

代码视图是只读的，用于查看与导出。想修改代码请走下一节的「载入编辑器」。

10.2 载入编辑器

这是图形界面与代码模式之间的桥梁：

  1. 在代码视图右上角点「载入编辑器」。
  2. 右侧会自动切到「高级」页签，代码被填入编辑器，可以自由修改。
  3. 点「运行」或按 Ctrl+Enter 执行。
  4. 画布立即显示运行结果；同时代码视图也会同步成你改过的代码。
什么时候用。需要 ggplot2 原生能力、而界面上没有对应控件时，例如自定义 scale_* 组合、 特殊的 annotation_custom、或者调用某个扩展包的生僻 geom。改完仍然可以点「存入图库」存档。
代码模式下来源会切换。一旦运行了自定义代码，画布显示的就是代码产出的图，而不是图层搭出来的图。 顶栏会出现「代码图」标签，点「返回我的图」可以切回。

10.3 智能补全

编辑器内置 R 代码补全，词表来自 ggplot2 生态的注册表与本机已安装的 R 包。

输入补全内容
geom_全部几何对象函数（约 180 个）
scale_全部标度函数（约 340 个）
theme_全部主题函数

第 11 章　项目、扩展与快捷键

11.1 项目文件

底栏右侧的「项目」下拉菜单提供：

  • 保存项目（JSON）：把当前完整绘图规格存成文件，可分享给他人或备份
  • 载入项目：恢复之前保存的项目，同时同步左侧数据源
  • 清空画布：从零开始

Glyph 还会自动保存草稿。如果意外关闭了窗口，下次打开时顶部会提示「发现上次未保存的草稿」，可以选择恢复或丢弃。

11.2 扩展管理

「扩展」页签列出可用的 ggplot2 扩展包（如 patchwork、ggrepel、ggsci、ggprism 等），显示是否已安装与是否启用。停用某个扩展后，依赖它的功能会明确提示，而不是静默失败。

11.3 快捷键

11.4 常见问题

现象原因与处理
拖窗口后图没变检查画幅面板里的「自适应画布」是否被关掉了（手动改过画幅会自动关闭）
图上多出一个图例某个属性被设成了「映射」而不是「常量」，去「美学」页签检查
打开图库条目后数据集变了这是预期行为：图库条目会连数据源一起还原，以保证映射有意义
拼图标题变大但子图字号没变plot_annotation 只作用于标注层，子图字号要到各自主题里改
导出检查不通过按提示逐项调整：通常是 dpi 不够、字号太小或背景不是白色
图看起来糊大屏上先确认「自适应画布」开着；导出时用 300 dpi 或选 SVG/PDF
推荐的上手路径。先用内置数据集画一张散点图，把「图层 → 美学 → 参数 → 标度 → 主题」走一遍； 然后试一次存入图库并重新打开，理解「更新 vs 另存」；最后到代码视图点一次「载入编辑器」， 看看图形操作对应生成了什么代码——这是理解 ggplot2 表达式最直观的方式。
